# Whaybench documentation

Whaybench puts Claude Code or Codex CLI in one window with a map of the conversation, your sessions, the agent's
answers and everything it shows you. Start with the first group, then look up what you need.

## Start

- [Install](install.md): Linux and Windows, checking a download, updating, going back a version, removing
- [Get started](getting-started.md): a first conversation in about 15 minutes
- [Windows setup help](windows.md): when the setup stops, and the work disk
